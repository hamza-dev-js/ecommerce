This project was built to practice and demonstrate:

- REST API design

- Real-world e-commerce features

It simulates a real online store with admin management.

## 🌟 Features

### Frontend
- 🎨 Modern responsive UI with Tailwind CSS
- 🛒 Shopping cart functionality
- 🔍 Product search and filtering
- 📱 Mobile-friendly design
- ⚡ Fast loading with React best practices
- 🖼️ Product image gallery with fallbacks

### Backend
- 🚀 RESTful API with Express.js
- 💾 PostgreSQL database integration
- 🔒 Secure authentication ready
- 📊 Product management system
- 🛡️ CORS enabled for cross-origin requests
- 📝 Comprehensive error handling

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Axios** - HTTP client
- **React Router** - Navigation

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **PostgreSQL** - Database
- **CORS** - Cross-origin resource sharing
- **dotenv** - Environment variables

## 🚀 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/products` | Get all products |
| GET | `/api/products/:id` | Get product by ID |
| POST | `/api/products` | Create new product |
| PUT | `/api/products/:id` | Update product |
| DELETE | `/api/products/:id` | Delete product |
| GET | `/api/products/search/:query` | Search products |
| GET | `/api/products/category/:category` | Get products by category |
